# results / results/_unverified

`results/_unverified/` holds metric JSONs carried over from the original repo
(`ablation_results.json`, `adaptive_holdout.json`) that **could not be
reproduced** from any code in the repository — there was no training pipeline,
no dataset, and no evaluation script in Stage 1.

They are treated as **unverified, from earlier experiments / placeholder** and
are **not** cited as achieved performance in the README, REPORT, or UI.

No accuracy / precision / recall / F1 is claimed by this project.
